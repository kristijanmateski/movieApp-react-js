# React Movie App

A movie rental web application built with React, Firebase, and Bootstrap. This app allows users to browse movies, rent them, and manage their rented movies. It includes Firebase authentication and a movie detail page.

## Features

- **Movie Listing**: Browse and filter movies by genre.
- **Movie Details**: View detailed information about a specific movie.
- **Rent Movies**: Rent a movie if you're logged in.
- **My Rented Movies**: View and manage movies you've rented.
- **Authentication**: Sign up, login, and logout using Firebase Authentication.

## Tech Stack

- **React**: Frontend library for building the user interface.
- **Firebase**: Backend for authentication and storing rented movies and comments.
- **Bootstrap**: Utility-first CSS framework for styling.
- **React Router**: For handling routing and navigation between pages.
